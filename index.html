How it works

1

Drop a song in. HertzShift reads its current tuning automatically — or tells you plainly when it can't, instead of guessing.

2

Pick a target. One click for 432, 440, 444, or 528 Hz — or type any custom tuning.

3

Convert & Verify. An independent check measures the new file and saves a tamper-evident certificate PDF next to it.

Built on honesty

The verification is genuinely independent. The code that checks the result shares nothing with the code that produced it — different algorithm, different measurements, enforced by automated tests.

It never fakes confidence. Content with no musical notes (speech, drums, ambient sound) has no tuning to detect — HertzShift says so instead of inventing a number. Wrong settings produce an honest FAILED with a plain-English explanation and a suggested fix.

Your audio stays yours. Everything runs offline on your computer. Nothing is uploaded, ever.
